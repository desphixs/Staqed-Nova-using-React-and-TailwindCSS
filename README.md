# Build Nova: The Thought Journal

You're building Nova, a minimalist "Thinking Tool" for researchers and writers. Nova is the opposite of noisy social media; it’s a private, clean space where you can "dump" thoughts as they come to you. You’ll use React to build a live-updating feed where users can type a thought, hit enter, and see it instantly appear at the top of their stream with a timestamp. It’s the perfect project to learn how to handle lists of data without the complexity of a backend database.
